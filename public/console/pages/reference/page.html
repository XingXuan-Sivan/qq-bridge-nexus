DSH 侧 MCP 工具

由 qq-bridge 的 MCP server 提供给 DSH agent；修改后需重启 DSH 才会刷新工具 schema。
工具说明
qq_status登录状态（只读）
qq_list_groups群列表（只返回白名单群）
qq_get_group_members群成员（只读，群号必须白名单）
qq_get_group_history群历史（只读，含 message_id，可作引用目标）
qq_send_group_message发群消息；可选 replyToMessageId 引用/回复
qq_reply专用“引用/回复”：在群里引用某条消息并发送文本
qq_send_private_message发私聊；可选 replyToMessageId 引用/回复
qq_slang_query查询已确认黑话/梗/网络表达（只读）
qq_slang_submitAI 提交陌生词/黑话给管理员筛选
二代仿真模式工具：qq_get_prompt / qq_get_unread_messages / qq_get_recent_messages / qq_social_state / qq_send_burst / qq_send_message / qq_wait_for_messages / qq_set_wake_config / qq_mark_read / qq_memory_* / qq_slang_query / qq_slang_submit 等。
